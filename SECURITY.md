# Security policy

## Supported versions

Security fixes are provided for the latest release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private **Security advisories → Report a vulnerability** flow in this
repository. Include reproduction steps, affected versions, and potential
impact. Please allow maintainers a reasonable period to investigate before
public disclosure.

## Safe use

- Never commit API keys or credentials.
- Prefer local model endpoints when working with sensitive source code.
- Review generated code and commands before applying or running them.
- Use a server-side proxy for cloud API keys in public web deployments.
- Download installers only from this repository's official Releases page.
